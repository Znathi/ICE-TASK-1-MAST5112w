What is the difference between padding and margin in React Native?
1.	Padding creates space between the content and the inside edge of its container. Margin creates space outside a component, separating it from other components.
In React Native, what does justifyContent: 'center' do to the children inside a View?
It centers the children along the main axis of the View.
What does alignItems: 'center' do to the children inside a View?
It centers the children along the cross axis of the View.
What happens when a user presses a Pressable component?
When a user presses a Pressable component in React Native, it triggers the onPress function.
